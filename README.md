## 🎯스터디 목표
- 꾸준한 알고리즘 학습을 통해 문제 해결 능력을 향상시키는 것을 1차 목표로 함
- 알고리즘 풀이 습관을 형성하여 실전 코딩테스트 대비 역량 강화
- 다양한 유형의 문제를 반복적으로 풀어 사고 확장 및 구현 능력 개선

## 📚 규칙
- **매일 백준 실버 등급 이상(혹은 프로그래머스 2단계 이상) 문제 하나 해결할 것**
- 따로 일정이 있는 경우(예: 여행 등) 미리 양해를 구하고 일정 만큼의 문제를 풀어두는 것 가능
- 미진행의 경우 공가 기준을 준수할 것
  - 취업 관련(면접, 국가자격증 취득, 코딩테스트 및 인적성검사), 본인 경조사(결혼, 사망 등) 등
  - 단, 조원들이 공통적으로 인정해주는 경우에는 스터디 참여 인정 (예: 스터디원 전원 공동 발표 준비)
- 무단 스터디 불참 시 벌금 제출 및 스터디원에게 알고리즘 강의 진행

## 📝 커밋 규칙
- 백준허브(BaekjoonHub)로 자동 업로드되며, 문제 풀이 파일 구조 및 커밋 메시지는 확장 프로그램 규칙을 따름
- 개별 커밋 정리는 자유롭게 하되, 자동 커밋을 임의로 수정할 필요는 없음

## 📸 참여 방식 & 인증
- 매일 문제 풀이 완료 후 단체 채팅방에 solved.ac ‘맞았습니다!!’ 화면 캡쳐로 인증
- 풀이 언어나 플랫폼은 자유(백준/프로그래머스 등)
- 사유로 인해 사전 이야기 후 일정분 선제출(미리 풀기) 가능
